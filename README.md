# 📝 OwnNotePad

A simple desktop text editor built with **Python and PyQt5**, inspired by the classic Windows Notepad.

OwnNotePad provides a clean interface for writing, opening, and saving text files, along with basic font customization and theme switching.

## ✨ Features

- **Text Editing** – Write and edit text using a simple writing area.
- **Create New Files** – Clear the editor and start a fresh document.
- **Open Files** – Open existing `.txt` files from your computer.
- **Save Files** – Save your notes as `.txt` files.
- **Font Customization** – Change the font family and font size.
- **Dark & Light Mode** – Switch between dark and light themes.
- **Simple Interface** – Minimal design focused on writing.

## 🛠️ Built With

- **Python** – Main programming language.
- **PyQt5** – Used to build the graphical user interface.
- **Qt Style Sheets (QSS)** – Used for application styling and themes.

## 📸 Features Overview

| Feature | Description |
|---|---|
| File Menu | Create, open, and save text files |
| Text Menu | Customize font family and size |
| Theme Button | Switch between dark and light mode |

## 🚀 Getting Started

Follow these steps to run OwnNotePad on your computer.

### 1. Clone the Repository

```bash
git clone https://github.com/Kettypie/OwnNotePad.git
```

### 2. Navigate to the Project Folder

```bash
cd OwnNotePad
```

### 3. Install Dependencies

```bash
pip install PyQt5
```

### 4. Run the Application

```bash
python OwnNotePad.py
```
